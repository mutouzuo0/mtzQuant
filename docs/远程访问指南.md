# mtzQuant 远程访问指南（M4, 设计 13 章）

> 本地优先框架的远程观看/控制配套：Tailscale 主方案（手机可看）+ 其余隧道手动指引。
> 认证默认关闭（tailnet 内网场景）；**分享/非 tailnet 场景必须开启**（13.5）。

## 1. 本地启动

```bash
mtzquant serve                        # 默认 127.0.0.1:8501
mtzquant serve --with-task configs/demo_dual_ma.json   # 启动即跑演示回测
```

浏览器打开 `http://127.0.0.1:8501`：监控 / 新建回测 / 历史对比 / 参数扫描 / 数据下载 / 帮助。

## 2. 认证（分享前必开）

`settings.json`：

```json
"server": { "host": "0.0.0.0", "port": 8501, "auth_enabled": true }
```

`secrets.json`（**不入库**）：

```json
{ "server": { "tokens": { "你的-operator-token": "operator", "你的-watcher-token": "watcher" } } }
```

- `operator`：全部权限（提交回测 / 暂停·恢复·终止 / 下载）；
- `watcher`：只读（历史 / 监控 / 报告）；对控制端点返回 403（13.5 能力矩阵）；
- 前端首次收到 401 会提示录入 token（存 localStorage）。

非本机绑定且认证关闭时，`mtzquant serve` 会打印启动警告。

## 3. Tailscale（主方案，13.5）

```bash
mtzquant remote --provider tailscale   # 检测客户端 + 打印 MagicDNS 访问地址
```

- 安装客户端：https://tailscale.com/download（手机 / 电脑 / 服务器同 tailnet）；
- 服务端：`mtzquant serve --host 0.0.0.0 --port 8501`（认证务必开启）；
- 手机/笔记本：Tailscale 内网地址（MagicDNS `mtzquant-server` 或 `100.x.x.x`）访问
  `http://mtzquant-server:8501`，响应式布局（≤768px）观看净值曲线/进度/控制。

## 4. 断线补帧（Y2，6.3/13.5）

WS 连接带 `last_event_seq` 断点续传：断线重连后从 `run_event_journal`（8.3.7）按
event_seq 回放缺失事件，曲线无缺口；`bandwidth=low` 客户端节流（daily_nav 每 5 日一推，
明细不推），弱网可用。

## 5. 其他隧道（手动指引，13.4；mtzquant 不自动安装）

```bash
# Cloudflare Tunnel
cloudflared tunnel --url http://127.0.0.1:8501
# ngrok
ngrok http 8501
# frp（自建服务）
# 配置 frps/frpc 将 8501 转发到公网
```

> 生产/分享务必：非 127.0.0.1 绑定 + `auth_enabled: true`；token 只存 secrets.json。

## 6. 移动端说明（13.5）

- 净值曲线优先 + 进度 + 核心指标卡；持仓/成交折叠 Tab；委托/日志默认收起；
- ECharts 触屏 dataZoom；
- `bandwidth=low` 建议手机端开启（节流放大）。
