# 适配器开发指南

> M2-P3 交付（设计 附录A 摘要版 / 4.2 / 4.4 / 4.5）。新增策略平台适配器的 8 步操作模板。
> 全程纪律：适配器只做「翻译」，禁止膨胀成第二引擎（import-linter 契约 4.3）。

## 1. 建包与协议

```text
mtzquant/adapters/<platform>/adapter.py      # 主适配器
mtzquant/adapters/<platform>/objects.py      # 平台对象投影（可选拆分）
```

实现 `StrategyAdapter` 协议（`mtzquant/adapters/base.py`）：
`load(strategy_path)` / `setup(account_view)` / `on_before_trading` / `on_bar` /
`on_after_trading` / `take_orders()` / `sync_orders(pairs)` / `finalize()` /
`run_initialize(ctx)`；`platform` 属性 = 注册名。

## 2. 列出 API 清单并标注 L0/L1/L2

| 级别 | 含义 |
|------|------|
| L0 | 官方语义全量（运行环境 g/log/context、下单族、基础数据、调度入口） |
| L1 | 常用子集（持仓查询、快照、主数据、日历） |
| L2 | 尽力或占位（结构化报错 + 替代建议, 4.9） |

登记到 `shared/compat.py` 的 `COMPAT_REGISTRY`（`register_api(platform, api, level)`），
`docs/compat/<platform>.md` 与清单保持一一对应（P3 评审）。

## 3. 复用 shared/ 内核，只写差异

- **g 容器** `shared/g_container.py`：双风格赋值（`g.x` / `g['x']`）。
- **log** `shared/log_api.py`：`log.info/warn(dual)/error` + printf `%` args 回退空格拼接。
- **context** `shared/context_factory.py`：内核 6 字段（current_dt/previous_date/universe/
  portfolio/timestamp/run_id）+ 平台扩展槽。
- **持仓投影** `shared/portfolio_view.py`：`UniformPosition/UniformPortfolio` + 平台投影
  （`jq_position_view` / `ptrade_position_view` / 各自 portfolio view, 4.4 投影表）。
- **下单族** `shared/order_apis.py`：`order/order_target/order_value/order_target_value/
  order_market` 五函数归一为 `OrderRequest`（K5）。
- **数据族** `shared/data_apis.py`：`DataApiCore`（PIT: as_of/knowledge_time/include_today,
  3.13）——`history/attribute_history/get_price/current_data` 统一核心。
- **报错** `shared/compat.py`：`NotImplementedApiError`（带平台名/级别/替代建议/实现指引）。
- **代码互转** `shared/code_style.py`：内部码 ↔ 平台码（`denormalize_code`）。

## 4. 注入采用 module.__dict__.update(namespace)，先于策略执行

```python
def load(self, strategy_path, context=None):
    code = Path(strategy_path).read_text(encoding="utf-8")
    namespace = dict(self._api_namespace())
    namespace["__name__"] = "joinquant_strategy"
    exec(compile(code, str(strategy_path), "exec"), namespace)
    self._initialize = namespace.get("initialize")
    # ... 生命周期钩子解析
```

## 5. 数据类 API 一律转发 MarketDataProvider 且显式传 cutoff

`shared/data_apis.py` 已封装；适配器命名空间里的 `get_history/get_price/...` 直接调
`DataApiCore`（注入 `provider` + `current_dt` + `phase`）。**禁止自行读行情文件**——
数据层只经 `mtzquant.data` 注入的 provider 访问（import-linter: adapters 不 import data? 否——
adapters 可 import `mtzquant.data.provider` 协议对象, 但禁止 import `mtzquant.engine.*` 实现）。

**交易类 API 只产生 OrderRequest，禁止自行改账户**（5.3.4）：下单走
`BrokerGateway.submit_request(req) -> str`（引擎 `take_orders` 通道），返回平台 Order
模拟回执（`wrap` 工厂）。撮合/记账/绩效只有引擎一份实现。

## 6. 注册

```python
def _register() -> None:
    from mtzquant.adapters.base import register_adapter
    register_adapter("<platform>", XAdapter)

_register()
```

注册后 `AdapterRegistry.detect(code)` 自动嗅探（native/joinquant/ptrade 规则见 base.py），
UI 平台下拉读注册表自动出现。

## 7. 为每个 L0 API 写注入用例

- 策略内调用 → 断言 `OrderRequest` 正确（code/direction/style/quantity/…）/ 数据列正确 /
  防未来（include_today 时点）。
- 见 `tests/adapters/{ptrade,joinquant}/test_*.py`（T-PT*/T-JQ* 探针机制: `g.probe` JSON 落盘）。

## 8. 更新 docs/compat/<platform>.md 与黄金用例

- `docs/compat/<platform>.md` 全表（L0/L1/L2 + S0-S4 + 已知近似清单）。
- 黄金用例平台版 `tests/golden/platform_<name>/`：复用 native oracle（D3 纪律），
  数据构造/六要素期望与 native 同源，只换「策略动作的表达方式」。
- 新增期望值必须附手算依据，禁止「跑一遍拿输出当期望」（测试方案 §11）。

## 新增 API 模板

```python
def your_api(self, ...) -> Any:
    """平台官方语义（4.9 登记 L 级）。"""
    core = self._data_core()          # 数据类
    return core.get_price(...)        # PIT 转发
    # 或
    oid, req = _submit(self._gateway, api="your_api", code=sec,
                       direction=..., style=..., clock=..., **kw)  # 交易类
    return self._wrap(oid, req)
```

未实现 API 用 `shared/compat.py::not_implemented` 抛结构化错误，绝不静默返回错误数据。
