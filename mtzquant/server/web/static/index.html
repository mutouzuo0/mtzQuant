帮助

mtzQuant Web 控制台——本地优先量化回测框架。

  • 监控页: 实时净值/进度/成交; 输入 run_id 订阅指定会话（留空 = 全部）;
  • 断线自动按 event_seq 补帧（resume 协议, 6.3/13.5）;
  • 新建页: 提交任务 JSON → 子进程隔离执行（D1）;
  • 历史页: 多 run 指标对照 + 净值对齐（10.3）;
  • 报告: 命令行 mtzquant report <run_id> 生成自包含 report.html。

认证: 非本机绑定时请开启 server.auth_enabled + secrets server.tokens（13.5）。

回测结束后可用 mtzquant report <run_id> 查看完整报告。
